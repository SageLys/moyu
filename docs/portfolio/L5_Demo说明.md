# Demo 入口与说明

链接：[https://sagelys.github.io/moyu/](https://sagelys.github.io/moyu/)

## 这个 Demo 想让你看到什么

它是一个被主动停掉的原型。配套文档论证了“压力曲线其实只作用在 QTE 上”，这里可以自己验一遍。

## 建议怎么玩（约 3 分钟）

1. 撑过 2–3 波领导巡查。留意两件事：巡查间隙里几乎一直在点，但点的永远是同一套；波次推进后 QTE 明显变难，而间隙那段的忙碌程度没怎么变。
2. 按 `T` 打开调参面板。33 项玩法数值全在这里，修改输入框会即时生效；可把“精神 每秒衰减”从 `-0.7` 改回 `-0.25`，感受调参前那一版有多空。
3. 按 `L` 可以立刻触发一次巡查，不用等。

## 操作方法

鼠标点击“开始”；平时可点击场景物件，领导巡查时按黄色高亮依次点击对应物件完成 QTE。`T` 显示/隐藏调参面板，`L` 立刻触发领导巡查。调参面板提供“重开一局 / 恢复默认 / 导出 JSON / 布局模式”。

## 当前完成度

已完成单局循环、资源衰减、领导巡查、QTE、四种结束结果、内置 33 项调参面板、配置校验、单元测试与公开部署。美术为原型级 SVG 与 AI 生成处理图；没有存档、账号、排行榜、移动端专门适配或遥测。

## 已知问题

- 原型的核心问题仍未解决：巡查间隙的操作虽频繁，却是重复的一套点击；压力提升主要发生在 QTE。
- 调参面板的 33 项控件当前实现为数字输入框，而非滑块；数值会即时生效，但无法按“拖动滑块”的方式操作。
- 调参面板是右侧 DOM 覆盖层：在 1366×768 下未越界，但会遮挡画面右侧一部分场景物件；可按 `T` 随时关闭。
- 平衡没有经过正式试玩或参数实验验证；数值用于展示判断，不代表已调优。
- 美术为占位/原型资产，尚未完成最终版权、品牌与无障碍审校。
- 仅验证桌面 1366×768 与 1920×1080；窄屏和触控设备没有专门适配。
- 没有声音设计，因此不存在音频自动播放反馈；也没有存档，刷新会开始新的一局。

## 构建与部署方式

在仓库根目录执行：

```bash
npm ci
npm run build
```

Vite 的 `base` 设为 `/moyu/`，使项目站点的资源路径正确；构建后脚本会剔除 AI 候选图、contact sheet、已选中但非运行时的源图和提示词目录。将 `dist/` 根目录发布到 `gh-pages` 分支，GitHub Pages 从该分支根目录提供服务。
